Online University Event Hall Reservation System

2023

Overview

A PHP/MySQL web application that replaces manual hall booking, with role-based access for users and admins. Tested locally on XAMPP.

For users

  • Check hall availability.
  • Book and cancel halls.
  • View booking history.

For admins

  • Update hall details.
  • Accept or deny booking requests.
